# Roblox Studio Bridge Terms

Roblox Studio Bridge is a development tool. Users are responsible for reviewing commands, keeping backups, respecting Roblox and OpenAI policies, and testing generated changes before publishing an experience.

The Always Allow option can automatically execute destructive edits and should only be enabled for a trusted GPT and trusted Bridge server. The service is provided without a guarantee that generated code is correct or suitable for production.
