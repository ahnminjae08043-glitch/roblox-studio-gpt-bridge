# Roblox Studio Bridge Terms

Roblox Studio Bridge is a development tool. Users are responsible for reviewing commands, keeping backups, respecting Roblox and OpenAI policies, and testing generated changes before publishing an experience.

Every mutation requires approval in Studio. Additional requests may wait in the device-specific queue until the user approves or rejects earlier commands. The service is provided without a guarantee that generated code is correct or suitable for production.

The plugin may be sold as a one-time Creator Store purchase. The hosted Bridge service is provided under reasonable fair-use limits, including command rate, daily usage, queue size, and payload limits. These limits protect availability for all purchasers and do not create a recurring subscription charge.
